SVG Scene Asset Library — 图鉴

Categorized SVG assets for AI scene composition engine. Browse, search, and integrate.

Asset Specification (编写规范)

File Naming

{category}/{id}.svg
  • characters/warrior.svg — humanoid characters
  • creatures/dragon.svg — non-human creatures/monsters
  • objects/chest.svg — interactable objects
  • items/sword.svg — holdable/wearable items
  • effects/fire.svg — visual effects (particles, auras)
  • backgrounds/forest-day.svg — full-scene backgrounds
  • ui/icon-heart.svg — UI elements (icons, frames, buttons)

SVG Root Attributes

<svg xmlns="http://www.w3.org/2000/svg"
     viewBox="0 0 W H"
     data-asset-id="{id}"
     data-layer="{layer}"
     data-tags="{tag1},{tag2},{tag3}"
     data-origin="center-bottom">

viewBox Sizes

LayerViewBoxNotes
character0 0 120 160Humanoids, standing pose
creature0 0 160 160Monsters, beasts (square)
object0 0 80 80Props, furniture
item0 0 60 60Holdable items (smaller)
effect0 0 200 200Visual effects, particles
background0 0 800 500Full-scene backgrounds
uivaries80×80 icons, 120×40 buttons

data-tags Format

data-tags="dragon,fire,drake,wyrm,龙,火龙,boss,monster"

Comma-separated, lowercase. Include: English name, synonyms, Chinese name, category, mood/element.
